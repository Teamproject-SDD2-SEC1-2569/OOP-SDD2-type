# ⌨️ TypeRush — Classroom & EdTech Edition

> แพลตฟอร์มทดสอบและประเมินผลการพิมพ์สำหรับห้องเรียน ด้วย Python บนสถาปัตยกรรม OOP พร้อมระบบความปลอดภัยและการวิเคราะห์ข้อมูลเชิงลึก เพื่อช่วยอาจารย์ติดตามพัฒนาการของนักเรียนได้อย่างแม่นยำ

---

## 📌 1. ภาพรวมโปรเจกต์ (Project Overview)

**TypeRush**  ออกแบบเพื่อแก้ปัญหาที่อาจารย์ไม่สามารถติดตามพัฒนาการฝึกพิมพ์ของนักเรียนได้อย่างใกล้ชิด ระบบเปลี่ยนการฝึกพิมพ์แบบเดิมให้เป็นรูปแบบห้องเรียนออนไลน์ ที่ปลอดภัย ป้องกันการโกงคะแนน และแสดงผลสถิติแบบเจาะลึกรายบุคคล พร้อมระบบกระดานผู้น ในห้องเรียนเพื่อสร้างแรงจูงใจ โดยยังคงรักษาความเป็นส่วนตัวของข้อมูลนักเรียนไว้

---

## 🎯 2. วัตถุประสงค์และปัญหาที่แก้ไข (Problem Statement & Solutions)

อาจจะต้องเอาตามนี้ไปก่อนนะ
*   **ปัญหา:** การฝึกพิมพ์ทั่วไปไม่มีระบบติดตามผล อาจารย์ไม่รู้ว่าเด็กพัฒนาขึ้นหรือไม่ หรือมีจุดอ่อนที่ตัวอักษรใด
    *   **ทางแก้:** สร้าง Teacher Dashboard แสดงกราฟอัตราการเติบโต (Growth %) และ Keyboard Heatmap ของนักเรียนแต่ละคน
*   **ปัญหา:** การปลอมแปลงคะแนน (API Spoofing) และการใช้บอทสคริปต์
    *   **ทางแก้:** ประมวลผล Keystroke Stream ทุกจังหวะการกดปุ่มที่ฝั่ง Server เท่านั้น พร้อม Algorithm วิเคราะห์ความผิดปกติของเวลา (Latency Variance)
*   **ปัญหา:** ความเป็นส่วนตัวของข้อมูล (Data Privacy)
    *   **ทางแก้:** ใช้ Role-Based Access Control (RBAC) นักเรียนจะเห็นเฉพาะสถิติสูงสุด (Highest WPM) ของเพื่อนร่วมห้อง แต่ประวัติเชิงลึกจะถูกจำกัดให้ดูได้เฉพาะอาจารย์และเจ้าตัวเท่านั้น

## ✨ 3. ฟีเจอร์หลัก (Key Features)

### 👨‍🏫 สำหรับอาจารย์ (Teacher Portal)
*   **Classroom Management:** สร้างห้องเรียนและออกรหัสเข้าร่วม (Invite Code) แบบสุ่ม
*   **Student Analytics:** ติดตามพัฒนาการรายสัปดาห์ (Weekly Growth), ค่าเฉลี่ย WPM และความแม่นยำ
*   **Problem Key Heatmap:** วิเคราะห์จุดอ่อนรายบุคคล แสดงปุ่มตัวอักษรที่นักเรียนใช้เวลาคิดนานหรือกดผิดบ่อยที่สุด

### 🧑‍🎓 สำหรับนักเรียน (Student Portal)
*   **Interactive Typing Arena:** หน้าต่างฝึกพิมพ์มินิมอล รองรับ Dark Mode (เทาชาร์โคล/ชมพู) และ Light Mode (ขาวนวล/ชมพูเบอร์รี) พร้อม Virtual Keyboard ที่เปลี่ยนสีตามการกดจริง (ฟ้า/เขียว/แดง)
*   **Highest WPM Profile Tag:** แสดงสถิติที่ดีที่สุดในวงเล็บท้ายชื่อ (เช่น `Alex_Speed (112 WPM)`) เพื่อความภาคภูมิใจ
*   **Classroom Leaderboard:** กระดานจัดอันดับความเร็วเฉพาะภายในห้องเรียน (#1, #2, #3...)

## 🏗️ 4. สถาปัตยกรรมระบบ (OOP & Security Architecture)

การพัฒนาระบบอิงตามมาตรฐานวิชาโครงสร้างซอฟต์แวร์ เพื่อให้ได้ High Cohesion และ Low Coupling:

*   **Encapsulation:** ซ่อนแอตทริบิวต์ `_highest_wpm` ให้อ่านได้อย่างเดียวผ่าน Property ป้องกันการแก้ไขจากโค้ดภายนอก
*   **Inheritance & Mixin:** คลาสแม่ `User` สืบทอดไปยัง `Teacher` และ `Student` พร้อมใช้ `TimestampMixin` เพื่อลดความซ้ำซ้อนของโค้ด (Diamond Problem)
*   **Composition:** โมเดล `Classroom` ประกอบด้วย (has-a) `Teacher`, `List[Student]`, และ `ClassroomLeaderboard` ทำให้แยกระบบจัดการง่ายขึ้น
*   **Polymorphism & Abstract Classes:** ใช้ Interface มาตรฐาน `BaseGameMode` สำหรับขยายโหมดการพิมพ์แบบจับเวลาหรือแบบนับคำ โดยไม่ต้องแก้ Business Logic เดิม
*   **Web Security:** ป้องกัน IDOR/BOLA อย่างเคร่งครัด ซ่อนประวัติเชิงลึก และใช้การเข้ารหัสรหัสผ่านที่ปลอดภัย
